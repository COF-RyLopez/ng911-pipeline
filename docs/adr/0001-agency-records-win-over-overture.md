# Agency records win over Overture

When a Source agency publishes its own address points or road centerlines, those are the Records in its
Package, even where Overture holds a point for the same place. Overture's point is often the same agency's
data copied months earlier through OpenAddresses, so the agency's current copy is fresher and is the one
the 911 authority is accountable for. Overture features with no matching Record go in only as Gap-fill
candidates. The alternative, Overture as the base with agency data as corrections, would have kept the
GERS-keyed design simpler but shipped stale data back to the agencies that published it.
