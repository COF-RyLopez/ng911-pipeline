# Agencies submit their own data; we prepare it and track where they stand

Each opted-in **Package** carries a NAD-template export, but the agency sends it, through its state's
address program where there is one and otherwise to nad@dot.gov: USDOT describes the NAD as aggregated
from state and local data, and we found no route for a third party to submit on an agency's behalf. The NAD
path is offered only once the agency's license is CC0 or public domain, since the NAD is published for
re-use without restriction. Addresses reach Overture through OpenAddresses (the license PR from ADR 0004),
because Overture doesn't list Esri Community Maps as an address source; Community Maps, with Esri's sharing
turned on, is the suggested path for buildings, roads and boundaries, and we link to Esri's own tools rather
than build an export. Each county page shows every agency's status on each path from the jurisdiction
registry, changed by hand only after the agency confirms. The trade-off is reach: nothing enters the NAD,
Overture or Community Maps without the agency acting, so coverage grows only as fast as agencies opt in.
